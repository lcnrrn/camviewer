# 캠뷰어 (TeslaCam 영상 뷰어)

테슬라 블랙박스(대시캠)·센트리 영상을 브라우저에서 보는 **비공식** 웹앱(PWA)입니다. Tesla, Inc.와 무관합니다.

- **영상은 기기 안에서만 처리**됩니다. 어떤 영상도 서버로 업로드되지 않습니다. (지도 타일·주소 검색 버튼 사용 시에만 OpenStreetMap에 접속)
- 멀티 카메라 동기 재생, 확대, 주행 정보(속도·위치) 표시, 구간 자르기·내보내기, 캡처, 안전신문고 신고 문구 도우미
- **암호화된 영상은 복호화하지 않습니다.** 차량에서 *컨트롤 › 안전 › 대시캠 녹화 암호화*를 끄거나, 차량의 자물쇠 아이콘 또는 dashcam.tesla.com 에서 먼저 해제하세요.
- 설치: 사이트 접속 후 브라우저 메뉴에서 "홈 화면에 추가"/"앱 설치"
